## Objective

Observe the starting point

## Prerequisites

An assistant and a new fictional folder; no engine, skill or API key required.

## Exercise

Ask for a meeting preparation note from the selected Cedar agenda. Save the unchanged first answer as baseline-v1.md and record elapsed time, missing information, unsupported claims and corrections. This baseline is an observation, not a promised poor result.

## Participant prompt

> Using only the selected Cedar meeting file, draft a short preparation note for the workshop lead. Cite the passages you actually used. State unknowns and decisions for the human reviewer. Do not browse, send, schedule or infer commercial capabilities from the agenda.

## Expected output

baseline-v1.md plus measurement row; preserve original output separately from annotations.

## Checks

The same evidence and task will be used later. Check each material claim, not just whether an answer sounds polished.

## Facilitator notes

Do not steer the initial assistant with the answer key. Ask participants which claims they would act on.

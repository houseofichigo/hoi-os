## Objective

Build governed knowledge

## Prerequisites

Selected import scope, reviewed governance and Node 22.14+ on the exercise machine.

## Exercise

Now install the engine using the installation guide in a fictional workspace. Run health and discovery with the actual assistant identity. Rehearse backup and separate restore. Preview the selected import, approve its manifest, preserve originals and inspect extracted passages. Draft a wiki, compare it and let the participant decide publication. Open exact source/page nodes in the map or accessible list. No AI key is required for ordinary import.

## Participant prompt

> Discover the installed engine operations and report actual host capabilities. Prepare a preview for only the selected fictional sources. Do not import before the manifest is reviewed. After an authorized import, show exact source revisions and extraction gaps; prepare a cited wiki draft using existing pages where appropriate. Stop before publication. Keep working documents distinct from authoritative records.

## Expected output

Import receipt, exact passages, wiki draft/comparison and recovery evidence.

Inventory systems before connecting: record what each holds, owner, sensitivity and route (supported native connector, authorized assistant tool/MCP, reviewed export, or none). Keep unknowns and all four connection states explicit; never include credentials or activate access from the inventory.

## Checks

Original hashes unchanged; denied data absent; no private directory chosen; map draft visibility follows existing rules.

## Facilitator notes

Use a prepared local runtime if setup takes too long, label it prepared rather than clean-machine verified.

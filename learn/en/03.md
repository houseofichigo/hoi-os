## Objective

Build the foundation progressively

## Prerequisites

Reviewed inventory; responsibility for the fictional workspace identified.

## Exercise

Create a separate private working folder outside the product checkout. Start with README and a short AGENTS manual. Use the foundation manifest to create one document at a time. Reuse confirmed sources, ask only unresolved questions, show the draft and record owner review. Preserve existing client names and mappings. Do not generate twenty invented policies in one pass.

## Participant prompt

> Inspect https://github.com/houseofichigo/hoi-os and the selected installed revision; if unavailable, state that and use the supplied versioned manifest. Create a new folder named My-HOI-Foundation outside the repository after confirming its location. Based on the inventory, draft only README.md and a minimal private-workspace AGENTS.md first. Then proceed one document at a time through the 20-responsibility manifest. Mark sources, open questions and review status. Never overwrite customized manuals or confuse developer instructions with workspace guidance.

## Expected output

Reviewed document map and progressively created drafts; open decisions remain explicit.

## Checks

20 responsibilities, not necessarily twenty new filenames. MEMORY/PROPOSED point to records. No file falsely claims a host, connection or schedule is active.

## Facilitator notes

Pause after the minimal manual. Demonstrate that a useful task can run before all documents are complete.

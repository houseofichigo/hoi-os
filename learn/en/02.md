## Objective

Inventory before writing

## Prerequisites

Module 1 and the selected fictional fixture folder.

## Exercise

Inspect filenames and selected readable content in read-only mode. Classify read, located but unread, unsupported and inaccessible. Record duplicates and likely restrictions. Exclude credentials, hidden runtime directories, backups and unrelated files. Do not ingest yet.

## Participant prompt

> Read the selected folder only. Produce a read-only inventory with relative path, file type, whether contents were read, apparent purpose, uncertainty and proposed next step. Do not move, rename, modify or ingest files. Never claim an unread file was analysed. Stop at an access boundary and report it without exposing private content.

## Expected output

inventory.md, with explicit selected scope and untouched source files.

## Checks

Compare before/after source checksums. Every inaccessible item remains unknown; filenames do not prove their contents.

## Facilitator notes

Include an unsupported file and a duplicate. Reward honest gaps rather than a perfectly filled table.

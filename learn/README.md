# Learn HOI OS — Build your harness

A business-team learning path over the existing HOI engine, 28-step method and optional Knowledge Hub. Canonical English; [French participant entry](README.fr.md). Source-prepared kit; independent human answer review and three-participant observation are not yet verified.

Start with a folder and an assistant. Modules 1–4 require no engine, provider key or installed skills. Install the engine only in module 5. Keep real company/client records out of this repository. Never run an exercise over a private workspace.

- [1. Observe the starting point](en/01.md) — [FR](fr/01.md); journey steps 1, 4.
- [2. Inventory before writing](en/02.md) — [FR](fr/02.md); journey steps 5, 6.
- [3. Build the foundation progressively](en/03.md) — [FR](fr/03.md); journey steps 1, 4, 8, 9.
- [4. Use AI with judgement](en/04.md) — [FR](fr/04.md); journey steps 10.
- [5. Build governed knowledge](en/05.md) — [FR](fr/05.md); journey steps 2, 3, 7, 11, 12, 13, 14, 15, 16.
- [6. Specialize one workflow](en/06.md) — [FR](fr/06.md); journey steps 17, 18, 19, 20, 21, 22.
- [7. Verify and resume](en/07.md) — [FR](fr/07.md); journey steps 20, 21, 25, 26, 27, 28.

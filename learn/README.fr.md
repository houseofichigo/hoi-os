# Learn HOI OS — Build your harness

Parcours métier fondé sur le moteur HOI, ses 28 étapes et le Knowledge Hub optionnel. [Source anglaise](README.md). Kit préparé ; revue humaine indépendante et observation de trois participants non vérifiées.

Commencer avec un dossier et un assistant. Modules 1–4 sans moteur, clé API ni installation de skills ; moteur au module 5. Ne jamais utiliser de données privées pour les exercices ni les déposer dans Git. Les étapes techniques 2–3 sont différées, sans renumérotation.

# Member mode

## Starting point

Use the available validated company foundation as reference. If it is unavailable, create a provisional profile and list the needed shared context without inventing it. Read only the member's selected work samples, relevant selected conversation material and current answers. Do not assume material from a shared account was authored by this member.

## Questionnaire — adapt to evidence

1. What is your role and what are you responsible for today?
2. Which three outputs do you produce most often? Who uses them?
3. For your most recent example, what did you receive and what did you deliver?
4. What steps did you take, and where did you spend the most time or make repeated corrections?
5. Which sources and examples did you rely on? Which are current?
6. What distinguishes a good result from an average one? Show an example if available.
7. In which application and format must you edit or finish the output?
8. Which decisions are yours, and which go to a colleague or manager?
9. Which clients/projects are currently assigned to you? Link to the actual assignment source.
10. What kind of assistance and response format would be useful? What part of your process should be preserved?
11. Which single recurring task should we test first, and what would count as success?

Each question is optional if reliable evidence already answers it. Reuse facts with their source, then ask for corrections. Avoid duplicating shared company rules or collecting unrelated personal details.

## Output profile

Write one concise profile containing role, responsibilities, collaborators, links to assignments, recurring workflows, preferred output/working formats, a real example, review points and the first pilot task. Include evidence references and unresolved questions. Split into several files only if volume or the user warrants it.

The member confirms their preferences and description of work. The appropriate lead confirms responsibilities and decision rights when needed. Member approval does not validate a company-wide policy. Do not copy full client knowledge or company instructions into every profile.

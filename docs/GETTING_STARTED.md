# Getting started

1. Choose a desired outcome and inspect the relevant skill in the catalogue.
2. If you do not have a compatible HOI OS app, use this as an instruction preview or a fork starting point. The new app is not publicly available yet; no substitute app should be generated by a skill.
3. With an existing compatible app, select a private workspace outside this checkout. Use your own profile and timezone. Keep originals and backups private.
4. Check engine API 1, workspace schema 17 and the skill's required operations. Follow the app's managed Codex/Claude Code adapter installation, preserving existing edits. A chat-only environment cannot access a local engine by importing Markdown.
5. For supported app imports, select an individual ZIP, inspect the preview, import a draft, compare and explicitly activate. Do not duplicate a bundled skill unnecessarily. Import and activation do not execute supporting files.
6. Reload the chosen assistant workspace and verify skill discovery and engine access. Run `hoi-onboard` only after those checks. Start with fictional data or one deliberately selected document, not an entire company folder.
7. Configure providers and connector scopes separately in the app. No keys, OAuth accounts or private webhook are included. Paid generation needs explicit configuration and disclosure permissions.

Before upgrading an existing app workspace, verify a backup and a separate restore rehearsal using the app's instructions. Never overwrite custom manuals or silently migrate private data during skill setup.

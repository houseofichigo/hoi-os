# Expertise plugin validation — local candidate 0.1.0

Implementation: 15 portable plugin manifests, 45 composed skill workflows, 37 new skill sources, two onboarding updates and Step 16 customization. No schema migration, service installation or live provider call.

## Completed focused checks

- All 36 new domain task routes resolve one exact active revision for their curated English and French phrases; missing inputs require clarification.
- Explicit selections, ambiguous multi-output requests, disabled skills and governance restrictions retain the existing route boundaries. No executions are created by routing.
- Fifteen ZIPs are byte-reproducible across separate outputs. Every bundled skill file matches the authoritative source and every file/ZIP checksum reconciles. Existing output directories are refused.
- Fictional client profiles preserve evidence, expose missing fields, reject unsupported permission fields, reject another client's prior profile, require an exact digest for review and invalidate that review after edits.
- Profile writes preserve existing files and refuse Git destinations. The helper records descriptive review only; it is not authentication or an engine approval facility.
- Deterministic decimal variance calculations handle a zero budget explicitly and reject mixed-unit row fields. Accounting interpretation remains a reviewed task.
- Thirty-seven new skills pass the Forge static audit. Static scans are heuristic; independent domain-quality review and fresh-host installation are not implied.
- Company canonical bundles, root skill index, maintenance checkpoint and registry hashes reconcile. The public general-purpose catalogue and private installed runtime remain unchanged.

Thirty-seven static skill audits passed without findings. Three fictional profile rehearsals (studio, retailer and learning charity) preserve explicit missing context and remain unreviewed/unactivated. Delivered archives contain 285 files across 15 plugin ZIPs and match their authoritative package sources. Company inventory/source validation covers all 122 indexed IDs; the 39 changed/new canonical bundles match their corresponding product files.

## Limits

No claim of professional certification, multilingual generalization beyond curated routing phrases, factual-support rates or semantic routing quality is made. Each skill includes complete, missing-input, conflicting-evidence and injection acceptance cases; these are author-authored review cases, not independent held-out model evaluations.

The public research register pins source commits, document hashes and license assessments. All new workflows are original HOI prose. Research references are not bundled dependencies or endorsements; mixed-license and unlicensed material has not been copied.

No plugin has been installed into a live host, submitted to a marketplace or published. Agent Plugins root-manifest support must be checked on the intended host. The existing local Hub and adapter tests do not establish Windows, Intel Mac, clean-host or live-provider certification. Client profiles are selected explicitly; there is no automatic profile loader or new authorization store.

## Remaining gates and limitations

- **Live schedules:** no Codex automation or n8n workflow was created, published or activated. The available n8n connector did not expose node discovery, validation, creation or publication. Template parameter shapes were inspected in official source; local structure checks cannot replace target-instance validation, saved-connection read-back and fictional execution. Update the installed n8n/plugin capabilities when those tools are required.
- **Always-on:** no daemon was installed. Reboot, OS credential access, storage availability, missed-run behavior on an actual scheduler and secured connectivity require a target-machine rehearsal. Docker or a remote host cannot assume access to HOI's loopback listener.
- **Quality:** independently human-reviewed routing labels, comparison with correct manual execution, factual-support/citation evaluation of live answers and measurable task/cost benefit remain pending. Automated fixture accuracy is not the proposed quality certification; routing is not enabled automatically for every host request.
- **Providers/connectors:** deterministic provider fixtures were used; no paid API call, live Google scope, new private source or remote export tool was activated. No live-provider or specialist-review accuracy claim is made.
- **Coverage:** assisted review uses bounded excerpts. Suggested text is held in findings until an owner uses the existing editor/review workflow. Notes without linked sources remain in the manual whole-knowledge scan. Existing connector size limits still require splitting oversized scopes. Native/host-export identity mappings are not guessed. Unknown source dates remain unknown.
- **Recovery:** uncertain paid outcomes stay blocked for inspection. This upgrade does not add a generic action-replay or force-unlock endpoint. Restored copies pause definitions, revoke grants and clear schedule observations.
- **Platforms/publication:** this is the development Mac, not a fresh machine or Windows/Intel/Linux certification. The retired Electron app is not rebuilt. Prior publication/history findings and pilot gates remain separate. No GitHub publication is performed by this upgrade.

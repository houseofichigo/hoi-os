# Company onboarding review scenarios

Use the skill with [fictional source material](sources.md) and one request from [cases.json](cases.json). Record the exact skill revision, supplied sources, output, reviewer and observed result outside the product checkout. The expected/forbidden criteria are a public development rubric, not held-out evaluation evidence.

Review evidence reuse, remaining questions, conflicting statements, source attribution and document ownership. These examples exercise company, member and client modes. No API calls, private account access or approvals are needed to read them. Automated package/adapter checks cannot prove the interview follows these instructions; a live host review remains separate.

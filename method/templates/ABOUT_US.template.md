This file says who we are, how we work and what we expect from an AI assistant. It is written once per
organisation and shared by every harness we build. Every governance file in the folder is generated from it and
from ROLE.md, and from nothing else.

It does not replace the documents. Signed amounts, dates, headcounts and invoice status are read in the
contracts, emails, transcripts and system exports, with a source cited. If this file and a document disagree,
the most recent dated document wins, and the assistant tells me.

A section left empty is written « to complete », with the question that would fill it.

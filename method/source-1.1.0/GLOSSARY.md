# Glossary

| Word | Meaning here |
| --- | --- |
| **Harness** | Everything around the model: role, rules, sources, procedures, permissions, tests — as files in a folder |
| **Host** | The assistant application that runs the loop: Codex, Claude Code, and others that read Agent Skills |
| **Owner** | The person the harness works for, who writes ABOUT_US.md and ROLE.md and approves every change |
| **Core skill** | One of the fifteen skills that ship with the method and are the same in every harness (called *socle* in HOI's French material) |
| **Role skill** | A skill written per harness from ROLE.md — the owner's own procedure (called *métier* in HOI's French material) |
| **Recipe** | A ready-made ROLE.md plus its proof — role skills, corpus, answer key — in its own repository |
| **Pack** | The slice of a corpus one group ingests; independent of the recipe they build from it |
| **Source** | An original document in `sources/`, read-only, with an id `src-NNNN` |
| **Extract** | A source's text cut into numbered passages (`¶1`, `¶2`…) in `.hoi/extracts/` |
| **Passage** | One citable unit of an extract: a paragraph, a speaker turn, a spreadsheet row, a calendar event |
| **Gap** | A source that could not be read. Never guessed, never cited |
| **Flag** | A passage that looks like an instruction to the AI, a payment change, a secrecy request or a hidden-character trick |
| **Citation** | `[src-0029 ¶21]` — the source and passage a fact comes from |
| **Wiki** | The cited synthesis: one page per subject the role tracks |
| **Governance set** | AGENTS.md and the files it points to, generated by `hoi-govern` |
| **Requested / enforced** | A requested rule is written and may be ignored by a model; an enforced rule is made true by something outside the model |
| **Locked state** | The JSON files only scripts or the owner may change: evals.json, skills.json, automations.json, the manifest |
| **Absolute check** | An evaluation check that fails the whole run whatever else was right |
| **Void run** | An evaluation run whose locked files changed; it counts for nothing |
| **Canary** | A unique token whose appearance in an output proves a rule was broken |
| **Judged check** | An evaluation check a model decides (tone, role, shape…), in a fresh session, quoting its standard |
| **Hand-off** | The checkpoint a skill writes to STATE.json when it finishes, stops or hands over |
| **Guard** | The optional Claude Code plugin whose hooks block a few actions before they happen |
| **Generality test** | A new recipe changes nothing outside its own folder |
| **Graduation rule** | A role skill three recipes needed, unchanged, becomes a core skill |
